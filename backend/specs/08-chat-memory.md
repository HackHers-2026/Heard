## Goal

Persist every chat exchange (user ↔ Gemini) per speech session so that:
- Gemini has conversational context across messages (not cold every call)
- The UI can replay the full thread on reload
- Each message is labelled with a phase and a short human-readable summary

## Updated model

```python
class ChatMessage(SQLModel, table=True):
    id:           str           = Field(default_factory=lambda: str(uuid4()), primary_key=True)
    session_hash: str           = Field(index=True)      # sha256(speech_id)[:16]
    speech_id:    Optional[str] = Field(default=None, foreign_key="speech.id")
    role:         str                                    # "user" | "model"
    phase:        str           = "preptalk"             # "preptalk" | "activetalk" | "talksummary"
    content:      str
    summary:      str           = ""                     # 3-5 word label generated by Gemini
    created_at:   str           = Field(default_factory=lambda: datetime.utcnow().isoformat())
```

---

## session_hash derivation

```python
import hashlib
def make_session_hash(speech_id: str) -> str:
    return hashlib.sha256(speech_id.encode()).hexdigest()[:16]
```

Stable, deterministic, ties entire conversation to one speech session.
Supports future anonymous pre-speech chat (speech_id=None → hash from temp token).

## API endpoints

### POST `/api/speech/{speech_id}/chat`

Send a message and get a reply. Auth required.

**Request body**
```json
{ "message": "Can you help me open more confidently?", "phase": "preptalk" }
```

**Response**
```json
{
  "reply":   "Start with a bold claim, not a hedge — own the room from word one.",
  "phase":   "preptalk",
  "summary": "opening confidence tip"
}
```

**Logic**
1. Derive `session_hash` from `speech_id`
2. Fetch last 10 rows (`LIMIT 10 ORDER BY created_at DESC`) → reverse → Gemini history
3. Call `gemini.chat(message, phase, history, metrics_context)`
4. Save two rows: `role=user` and `role=model`, both with `phase` and `summary`
5. Return reply + phase + summary

---

### GET `/api/speech/{speech_id}/chat`

Fetch full conversation thread. Auth required.

**Query param:** `?phase=preptalk` (optional filter)

**Response**
```json
{
  "messages": [
    { "role": "user",  "content": "...", "phase": "preptalk",  "summary": "asked about opener", "created_at": "..." },
    { "role": "model", "content": "...", "phase": "preptalk",  "summary": "opening confidence tip", "created_at": "..." }
  ]
}
```

## Gemini integration — `services/gemini.py`

Add `chat()` function.

```python
def chat(speech_id: str, message: str, phase: str, history: list, session: Session) -> dict:
    # history = [{"role": "user"|"model", "parts": [content]}, ...]

    phase_context = {
        "preptalk":    "You are a warm speech coach helping the user prepare. Be encouraging.",
        "activetalk":  "You are a real-time coach. Be terse — one nudge, ≤15 words.",
        "talksummary": "You are a reflective coach reviewing a completed speech. Be growth-focused.",
    }

    if _stub_mode():
        stub_replies = {
            "preptalk":    "You're ready — start strong and own the room.",
            "activetalk":  "Slow down slightly, you're doing well.",
            "talksummary": "Strong structure. Work on reducing filler words next time.",
        }
        summary = _stub_summary(message)
        return {"reply": stub_replies[phase], "phase": phase, "summary": summary}

    model = genai.GenerativeModel(
        "gemini-1.5-flash",
        system_instruction=phase_context[phase],
    )
    chat_session = model.start_chat(history=history)
    resp = chat_session.send_message(message)
    reply = resp.text.strip()

    # Ask Gemini for a 3-5 word summary of this exchange
    summary = _generate_summary(message, reply)

    return {"reply": reply, "phase": phase, "summary": summary}


def _generate_summary(user_msg: str, model_reply: str) -> str:
    """3-5 word label for this exchange. Falls back to first 4 words of user message."""
    if _stub_mode():
        return _stub_summary(user_msg)
    try:
        model = genai.GenerativeModel("gemini-1.5-flash-8b")
        prompt = (
            f'User: "{user_msg[:100]}"\nReply: "{model_reply[:100]}"\n'
            "Summarise this exchange in 3-5 words. No punctuation. Lowercase."
        )
        return model.generate_content(prompt).text.strip()[:40]
    except Exception:
        return _stub_summary(user_msg)


def _stub_summary(text: str) -> str:
    words = text.split()
    return " ".join(words[:4]).lower().rstrip("?.!")
```
